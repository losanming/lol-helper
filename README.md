# 基于Ai的英雄联盟LOL对局分析工具

## 项目介绍
本项目基于Golang + wails + Ollama + Deepseek-r1:14b模型等开发，针对性的结合op.gg的主要数据进行数据训练。主要功能为对英雄联盟阵容、对局进行实时分析，并生成bp方案、对线思路和团战技巧等分析报告。

## 预计完成功能
- [x] 英雄分析
- [x] 当前阵容分析
- [x] bp方案分析
- [x] 对线思路分析
- [x] 团战技巧分析

## 产品定位
本产品旨在帮助玩家在英雄联盟中提高技能，提高对局效率，提高胜率。

## 产品雏形
本产品是一个基于Ai的对局分析工具，用户可以在本产品中选择自己喜欢的英雄，并实时分析当前阵容、bp方案、对线思路和团战技巧等。
